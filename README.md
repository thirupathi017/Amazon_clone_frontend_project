# Amazon 2.0 Frontend Clone

A comprehensive e-commerce UI clone of Amazon featuring product categorization, responsive design, and dynamic content rendering. 

## 🚀 Live Demo
[View Live Demo on Vercel](https://amazon-clone-frontend-project-git-main-thirupathi-ss-projects.vercel.app/)

## 🛠️ Built With
- **React.js (React 19)** - Frontend framework
- **Tailwind CSS** - Utility-first CSS framework for rapid UI development
- **JavaScript (ES6+)** - Core logic
- **HTML5 & CSS3** - Markup and styling

## ✨ Features
- **Responsive Layout:** Adapts beautifully across mobile, tablet, and desktop screens.
- **Hero Slider:** Interactive image carousel for featured promotions.
- **Dynamic Product Grid:** Categorized grid layout showcasing various deals and products.
- **Modern UI Elements:** Replicates the distinct Amazon styling including the Navbar, search bar, and secondary navigation.
- **Product Sliders:** Horizontal scrolling sections for specific product categories.

## 💻 Running Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/thirupathi017/Amazon_clone_frontend_project.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Amazon_clone_using_REACT
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```

The application will launch in your browser at `http://localhost:3000`.
